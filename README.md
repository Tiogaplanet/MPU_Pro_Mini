# MiP Power Up: Pro Mini
An Arduino Pro Mini adapter board for The WowWee MiP robot.The three files in the MPU_Pro_Mini folder are written in Eagle, are based on Sparkfun's original MiP ProMini Pack, and were updated by [adamgreen](https://github.com/adamgreen) to use the 5-volt, 16 MHz version of the ATmega328p.

While these files can be used to print the MiP Power Up - Pro Mini printed circtuit board (PCB), some knowledge in doing so is expected on the part of the user.

An update is pending that will migrate the project to KiCAD, and provide support support and tutorials to the user.
